## 🚀 Featured Project

<div align="center">

### [❤️ Heart Disease Prediction with Neural Network](https://github.com/KhaniHadis/heart-disease-neural-network)

</div>

A feed-forward neural network implemented **from scratch using NumPy** for binary heart disease classification.

- ⚙️ Forward propagation & backpropagation
- 📉 Gradient descent optimization
- 🔧 Hyperparameter tuning
- 🎯 **85.25% Accuracy**
- 📈 **92.42% ROC-AUC** on a held-out test set
