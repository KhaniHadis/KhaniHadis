## 🚀 Featured Project

### 🫀 Heart Disease Prediction with Neural Network

A feed-forward neural network built **from scratch using NumPy** for binary heart disease classification.

⚙️ Implemented:

- Forward propagation
- Backpropagation
- Gradient descent
- Hyperparameter tuning

📊 **Test Results**

| Metric | Result |
|:---:|:---:|
| Accuracy | **85.25%** |
| ROC-AUC | **92.42%** |
